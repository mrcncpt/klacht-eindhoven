Klacht NU

Eerste keer hier? Voeg deze pagina toe aan je startscherm.
Daarna = één tik op icoon = klacht ingediend.

Voeg toe aan startscherm

Android (Firefox): Menu (⋮) → Toevoegen aan startscherm.

iPhone (Safari): Deelmenu (deel-knop onderaan) → Zet op beginscherm.

Desktop: Bladwijzer toevoegen (Ctrl+D).

→ Naam: Klacht NU

Eerst installeren

Voor het script werkt: installatie-instructies bekijken

Tikt iemand op het Klacht NU-icoon vanaf homescreen, dan wordt automatisch je klacht ingediend.
