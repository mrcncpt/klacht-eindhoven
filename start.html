Klacht NU

Eindhoven Airport — automatische klachtmelder

Deze app dient automatisch een geluidsklacht in bij het Casper-portaal van Eindhoven Airport.

Tik op één van de knoppen hieronder → het script vult alle 4 stappen voor je in (datum vandaag, tijd nu, jouw gekozen oorzaak) en klikt op Verstuur.

Je werkt op je eigen Casper-account. Geen data wordt elders opgeslagen.

✓ Klacht NU staat op je startscherm — kies hieronder een klachttype.
✓ Reset gelukt — installatiestatus is gewist.

Welk type klacht?

🏠 Geluid in huisVliegtuig hoorbaar binnen — meest gebruikt 🌳 Geluid buitenVliegtuig hoorbaar in tuin / op straat 🌙 SlaapverstoringWakker geworden / niet kunnen slapen
