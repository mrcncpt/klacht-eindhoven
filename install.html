Klacht NU — installatie

5–6 stappen, ongeveer 3 minuten

Wat doet deze app? Klacht NU dient automatisch een geluidsklacht in bij het Casper-portaal van Eindhoven Airport.

Na installatie tap je vanaf je startscherm → kies je het klachttype (in huis / buiten / slaapverstoring) → het script vult datum, tijd en oorzaak in en klikt op Verstuur. Geen 8 klikken meer per klacht.

Iedereen logt in met zijn eigen Casper-account. Geen data wordt elders opgeslagen.

✓ Reset gelukt — installatiestatus is gewist.

2

"Allow user scripts" aanzetten

Belangrijk: Chrome blokkeert standaard userscripts. Activeer ze:

  1. Plak in adresbalk: chrome://extensions/
  2. Zet Developer mode aan (rechtsboven)
  3. Zet Allow user scripts aan
Zonder deze stap doet het script helemaal niets.

Veelgestelde vragen

Krijgt iemand anders mijn account te zien?

Nee. Iedereen logt in met zijn eigen Casper-account.

Wat als het script niets doet?

Op Chrome: check Allow user scripts. Firefox Android: check Tampermonkey site-toegang. iPhone: check Userscripts in Safari-instellingen.

Werkt het op normale Chrome op Android?

Nee. Chrome op Android steunt geen extensies. Gebruik Firefox.

Iets resetten?

Klik ↻ Reset installatiestatus om de "al geïnstalleerd"-flag te wissen.
