Klacht NU — installatie

5 stappen, ongeveer 3 minuten. Je hebt een Casper-account nodig.

1

Firefox installeren

De gewone Chrome op Android steunt geen extensies. Daarom: Firefox.

▶ Open Play Store — Firefox Open Firefox één keer na installatie. Daarna kom je terug naar deze pagina.
2

Tampermonkey toevoegen

Open onderstaande knop in Firefox (niet Chrome) en klik op "Add to Firefox".

▶ Open Tampermonkey-extensie Sta toe op alle sites als hij dat vraagt.
3

Klacht-NU script installeren

Klik onderstaande knop — Tampermonkey toont een install-prompt. Klik Installeren.

▶ Installeer Klacht-NU script
4

Log in op Casper-portaal

Open en log eenmalig in. Je inloggegevens worden lokaal in je telefoon bewaard.

▶ Open Casper-portaal Geen account? Klik bij Casper op "Maak een account aan".
5

Klacht-NU op startscherm zetten

Open onderstaande pagina, en voeg toe aan je startscherm via Firefox-menu (⋮) → Toevoegen aan startscherm → noem het Klacht NU.

▶ Open Klacht-NU startpagina De pagina wacht zelf op je en doet pas iets als je op "Klacht NU indienen" tikt of na de installatie het icoon gebruikt.
Klaar? Tik op je homescreen-icoon → portaal opent → groene banner verschijnt → 4 stappen lopen automatisch → klacht ingediend.

2

"Allow user scripts" aanzetten

Belangrijk: Chrome blokkeert standaard userscripts. Activeer ze:

  1. Plak in adresbalk: chrome://extensions/
  2. Zet Developer mode aan (rechtsboven)
  3. Zet Allow user scripts aan (knop verschijnt)
Zonder deze stap doet het script helemaal niets. Hier strandde Ralf ook.

Veelgestelde vragen

Krijgt iemand anders mijn account te zien?

Nee. Iedereen logt in met zijn eigen Casper-account. Het script doet niets meer dan wat jij zelf zou klikken.

Wat als het script niets doet bij het tikken op het icoon?

Op Chrome: check of Allow user scripts aan staat (chrome://extensions/, developer mode → toggle). Op Firefox Android: check Tampermonkey site-toegang („Op alle sites”). Op iPhone: check of Userscripts-extensie in Safari aanstaat.

Werkt het op normale Chrome op Android?

Nee. Chrome op Android steunt geen extensies. Gebruik Firefox.

Welke gegevens worden er ingediend?

Standaard: vandaag, huidig tijdstip, oorzaak Geluid, suboorzaak Geluidkwaliteit in huis, geen antwoord gewenst. In het script kun je dat aanpassen (bovenaan in SETTINGS).

Wat als er een Google-vinkje verschijnt?

Het portaal heeft een latente reCAPTCHA. Komt die ooit tevoorschijn (anti-spam), tikken jij even op het vinkje + Verstuur. Daarna pakt het weer over.
